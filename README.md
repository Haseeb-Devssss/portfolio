# Haseeb Khan | AI Automation & Web Developer

My personal portfolio website. I build modern websites, AI chatbots and automated business workflows with **n8n** and **Make**.

🔗 **Live site:** https://portfolio-omega-seven-kz1zmewaxd.vercel.app

---

## Services

- **Websites:** fast, responsive business websites and landing pages
- **AI chatbots:** chatbots that answer customers using the business's own information
- **Automation:** lead management, email follow-ups, Google Sheets and CRM workflows with n8n and Make

## Built with

- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- JavaScript (vanilla, no frameworks)
- Hosted on [Vercel](https://vercel.com), which redeploys automatically on every push to `main`

## Run it locally

```bash
git clone https://github.com/Haseeb-Devssss/portfolio.git
cd portfolio
```

Open `index.html` in a browser, or use the **Live Server** extension in VS Code and click **Go Live**.
